# 录入应用 ⇄ 核心系统 改造契约（P3）

> 面向：蓄电池电压录入应用（WorkBuddy）开发方 / 现场使用者。
> 核心系统＝Duty-Assistant da_core（本机权威账本 + 判定 + 输出投影）。
> 铁律：**表格只有核心系统能写**；应用与自动化一律不再直写 AI 表格。
>
> **2026-09-21 更新**：§4 的「核心 /intake 直收」已由《输入通道 v2 · 需求》
> （`docs/input-channel-v2.md`）取代——改为核心**主动拉取**应用侧只读接口（内网零暴露），
> 并以「主路失败时自动转投群」为兜底。

## 1. 现状与问题

| 环节 | 现状 | 问题 |
| --- | --- | --- |
| 提交 | 应用直写 AI 表格（旧口径自动化并行判定） | 双写者冲突、口径旧、无审计 |
| 降级 | 复制文本发钉钉群（4 行展示格式） | **缺 3 个必填字段**（直流系统/浮充电压/测试性质），核心无法入库 |
| 判定 | 应用内 13.20~13.80 旧口径 | 核心已改可配置口径（2V 1.85–2.35 / 12V 11.85–13.80） |

核心侧已就绪：账本、判定（免签自动定稿）、表格投影（唯一写者）、群消息接入口（每 5 分钟轮询用户配置的生产群）、催办引擎、月报。

## 2. 目标架构（单向）

```
录入应用 ──(A) 群降级文本【过渡】──▶ 核心系统 da_core ──▶ AI 表格（只读投影）
        └─(B) HTTP 提交接口【下一步】──┘
```

应用职责收缩为：**采集数据 + 生成提交报文**；不再判定、不再写表。

## 3. 通道 A（过渡，立即可用）：群降级文本·扩展格式

应用「复制降级文本」按钮输出的文本**必须**含以下全部行（每行独立，顺序不限；组间空行）：

```
# 蓄电池电压测量数据
# 提交时间: 2026-09-21 14:30
[组别] 3号组(12只)
[温度] 23
[直流系统] DC-003
[浮充电压] 13.50
[测试性质] 定期
[数据] 1:13.36,2:13.38,3:13.35,...
```

规则：

1. 首行标题固定 `# 蓄电池电压测量数据`（钉钉会把 `#` 行转成加粗、并折叠换行——核心解析器已兼容两种形态，应用不必变通）。
2. `[直流系统] [浮充电压] [测试性质]` 为**必填**；现场确实无法填写时输出 `未填`，由核心按缺字段拒收并在群内回执提示补齐（不允许省略该行）。
3. `[数据]` 一行内全部电池：`序号:电压`，逗号分隔，序号从 1 升序。
4. `提交时间` 必须是真实时间（不可未来）；多组发送在同一条消息中用多个 `[组别]` 块。
5. 群内回执语义（由核心自动回复，实际文案以群内为准）：
   - `⚠️ 未入库：…缺必填字段（直流系统编号/浮充电压/测试性质）` → 补齐后**重发整条**；
   - `⚠️ 未入库：…同日同组已有记录，无需重发` → 不需重发（防重复）；
   - `✅ 已入库：{组} {N} 只（异常 {M}）` → 入库成功摘要（重放不回执，防刷屏）。

## 4. 通道 B（下一步）：HTTP 提交接口

核心系统将提供 `POST /intake`（本机 127.0.0.1，token 认证），请求体 = 现有提交 JSON：

```json
{
  "client_submission_id": "uuid-防重发",
  "operator": "张三",
  "submitted_at": "2026-09-21T14:30:00+08:00",
  "groups": [{
    "group": "3号组(12只)", "dc_system_id": "DC-003", "float_voltage": 13.5,
    "test_kind": "定期", "env_temp": 23,
    "items": [{"no": 1, "volt": 13.36}, ...]
  }]
}
```

- 幂等：同 `client_submission_id` 重发返回原回执（不产生第二条记录）。
- 回执：`{"ok": true, "groups": [{"record_uid", "rev", "lifecycle", "verdict"}]}`；拒收含 `validation`（每条错误含定位）。
- 应用侧改造点：提交 URL 从「表格 API」切到核心 /intake；去掉应用内判定与写表逻辑；失败时自动退回通道 A 的扩展文本。

## 5. 应用需删除的旧逻辑

- 直写 AI 表格的全部代码路径；
- 应用内阈值判定（13.20~13.80 等硬编码）；
- 与 X-APM 自动化「蓄电池电压测量自动判定1」相关的联动（该自动化已在钉钉侧停用）。

## 6. 验收清单（应用侧）

- [ ] 降级文本含 3 个必填行（含 `未填` 分支）；
- [ ] 提交时间取真实时钟；
- [ ] 通道 A 消息在群内收到核心 `✅ 已入库` 回执；
- [ ] 通道 B 联调：同报文重发返回同 UID（幂等）；
- [ ] 应用不再写表（表格变更仅由核心发起）。
