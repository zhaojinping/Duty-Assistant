# 输入通道 v2 · 需求（拉取式主干 + 自动发群兜底）

> 定调（2026-09-21，双方负责人）：**不向公网暴露核心侧（内网）任何入口**。核心输入模块改为**主动拉取**公网数据；应用侧主路失败时**自动转投协同群**（替代人工复制）。本文件替代此前契约 §4 的「核心 /intake 直收」方案。

## 0. 架构（v2）

```
录入页 → 应用后端
   ├─ 主路：提交写入公网侧「待拉取存储」
   └─ 兜底：主路失败 → 自动把扩展文本投到「APM测试」群
核心 da_core 输入模块（本机、无对外入口、只出站）
   ├─ 拉取适配器（定时）：GET 应用侧只读接口 → 入库
   └─ 群接入口（每 5 分钟，已在运行）：兜底通道入库
        ↓ 两路共用同一入库管线（幂等 + 判重，见 §3）
     账本 → 判定 → 表格投影（核心唯一写者）→ 回执
```

## 1. 兜底：提交自动转投群（立即实施）

原来：主路失败 → 页面展示文本，**人工**复制发群。
现在：主路失败 → 应用后端**自动**把降级扩展文本发到「APM测试」群。

1. 群里新增一个**自定义机器人**（安全设置：加签；由群管理员侧配置），应用后端持有 webhook 地址+密钥；若贵方已有等价发群能力（组织级机器人「仅发消息」权限），亦可替代。
2. 发送内容＝与现降级扩展文本一致（含 3 必填行）；建议附「【自动转投】」标记便于识别。
3. 页面提示改为：「✅ 已自动转投协同群，入库回执见群（约 5 分钟内）」。
4. 发送失败本地重试 2 次；仍失败才退回现有「复制文本」人工路径（最后防线）。

**过渡期规则**：拉取接口（§2）就绪前，自动转投＝主路（每次提交都自动发群）；§2 就绪后，自动转投降为纯兜底（仅主路失败时触发）。

## 2. 主干：拉取式只读接口（核心侧主动拉）

由应用侧提供只读接口（公网可访问）：

```
GET {BASE}/api/submissions?since={游标}&limit=100
Authorization: Bearer <对接 token>
```

返回：

```json
{
  "items": [
    { "client_submission_id": "6f18eadb-…", "operator": "…",
      "submitted_at": "2026-09-21T13:31:43+08:00",
      "groups": [ { "group": "3号组(12只)", "dc_system_id": "直流通信电源A",
                    "float_voltage": 13.5, "test_kind": "定期", "env_temp": 22,
                    "items": [ {"no": 1, "volt": 13.36} ] } ] }
  ],
  "next_cursor": "…",
  "has_more": false
}
```

要求：

- **游标单调、不丢不重**（服务端序号或「时间+ID」双键，并发写安全；核心侧只按 next_cursor 前进）；
- 报文与页面提交**同源同构**（即契约 §4 报文原样保存，不需要任何改写）；
- **数据保留 ≥ 30 天**（核心侧停机/维护期间不丢数据）；
- **token** 双方约定（核心侧本地安全存储，不入 Git）；接口只读、只含提交数据，不含表格/账号/任何其它资源；
- 接口未就绪前，核心侧按本契约以**模拟数据自测**，接口一就绪即联调。

## 3. 双通道叠加语义（防重）

- 同一 `client_submission_id` 重复到达（拉取重扫）→ 核心幂等判重，**不重复入库、不重复回执**；
- 同一笔提交经两条路各到达一次 → 业务判重键（站+日期+组别+直流系统+性质）拦截，第二条判「同日同组已有记录」；
- 因此**冗余投递安全**：两条路都收到也不影响账本正确性。

## 4. 就绪顺序

1. **§1 先行落地（立即）**：人工复制环节消失；
2. §2 双方各自准备（应用侧：接口+存储+token；核心侧：拉取适配器）；
3. 联调通过后切主路；群通道持续可用（已验收）。

## 附：§2 对接实况（2026-09-21 对方交付）

- 鉴权头：`X-Submissions-Token`（**勿用 Authorization**——对方云端入口的反向代理会注入/覆写该头）
- 响应：`{items:[{seq, received_at, payload}], next_cursor, has_more}`；`payload` = 提交报文原样
- 游标：`since` 初始 `0`，此后用 `next_cursor`；保留期 30 天；同 `client_submission_id` 不重复存储
- 过渡期双轨：提交同时入待拉取存储 + 自动转投群；联调通过后对方切「纯兜底」
- 核心侧实现：`da_core.pull_intake`（CLI `pull-remote`）；入库回执策略待定（联调结论）
